智能体记忆与做梦：通过离线整理让 AI 实现跨会话长期进化

文章背景与核心概要

在认知科学中，人类通常是在清醒时经历生活，并在睡眠或休息中通过海马体与大脑皮层的协作将瞬时体验固化为长期知识。Anthropic 的最新研究探索了 AI 智能体如何借鉴这一生物学机制，破解跨会话“用完即忘”的瓶颈难题。通过将原始对话记录、记忆笔记、网络化维基 (Wikis) 与一种被称为“做梦 (Dreaming)”的离线反思机制有机结合，AI 智能体能够在不同任务会话的间隔期自主纠正认知偏差、提炼核心经验并动态重塑记忆层级。这一机制不仅在复杂的持续学习基准测试中大幅超越了无状态基准模型，也为构建具备长期自主进化能力的下一代 AI 智能体奠定了关键基础。

摘要

Summary

在认知科学中，生命始终在向前经历，但唯有通过记忆巩固 (Memory Consolidation) 才能向后理解——在人类睡眠或休息时，大脑会重放近期的体验，并将其深度整合至大脑皮层 (Neocortex) 中。如今，AI 智能体 (AI Agent) 也面临着极为相似的处境。本文将深入探讨现代大语言模型（特别是 Claude）如何在不同会话之间构建、提炼并高效运用长期记忆。通过将原始会话记录、记忆笔记、前沿维基 (Wikis) 知识库，以及一种被称为“做梦 (Dreaming)”的离线优化机制有机结合，AI 智能体能够真正从过去的交互中汲取经验、修正事实偏差，并敏锐预测未来任务所需的核心上下文。

In cognitive science, life is lived forward but understood backward through memory consolidation—a process where the brain replays recent experiences during sleep or rest and integrates them into the neocortex. AI agents encounter a remarkably similar bind. This article explores how modern language models (specifically Claude) structure, refine, and utilize long-term memory across sessions. By combining session transcripts, memory notes, advanced wikis, and an offline optimization process known as dreaming, agents can learn from past interactions, correct factual drifts, and dynamically predict what future contexts will require.

1. 引言：人类与机器面临的共同困境

1. Introduction: The Human and Machine Bind

💬 [名言引用 / Quote]:
“生活只有在向后回顾时才能被理解，但生活必须向前经历。” —— Søren Kierkegaard

💬 [原文引用 / Original Quote]:
"Life can only be understood backward, but it must be lived forward." — Søren Kierkegaard

人类在日常活动中会持续通过海马体 (Hippocampus) 编码瞬时记忆。然而，只有极少数经过筛选的关键经历才会被进一步固化为大脑皮层中的长期知识，而这一沉淀过程往往在我们入睡或休息的离线状态下悄然完成。AI 智能体的记忆系统同样可以借鉴这种分工哲学：利用两次任务交互之间的闲暇时间重新梳理并重组上下文信息——这一机制被形象地称为“做梦 (Dreaming)”。借助做梦，AI 智能体得以从容复盘历史日志、修正此前犯下的错误，并沉淀出高度稳健的知识表征。

As humans, we constantly encode memories via the hippocampus. Only select experiences, however, are consolidated into long-term knowledge in the neocortex, often occurring offline while we sleep or rest. Agent memory can use a similar division of labor. By leveraging idle time between interactions to reorganize context—a process called dreaming—AI agents can reflect on logs, fix mistakes, and produce robust knowledge representations.

2. 记忆笔记

2. Memory Notes

所谓“智能体记忆”，特指 AI 智能体从实践经验中沉淀而来、并能在不同会话之间以可读上下文形式长期保留的知识系统。这里需要特别区分的是：它既不属于大模型底层的固定权重，也不等同于单次会话中的即时上下文学习 (In-Context Learning, ICL)，更不同于简单的对话上下文压缩摘要。

"Agent memory" refers to knowledge gained from experience—retained between sessions as readable context—excluding model weights, single-conversation in-context learning, or compaction summaries.

正如同人类大脑利用神经化学信号对重要记忆打上标记、以便在后续离线状态下重放和稳固一样，Claude 也能够主动标记出关键的显著事件，或将探索过程中的洞察直接记录到持久化的记忆存储库中（例如专门存放记忆笔记的文件夹）。

Just as chemical signals mark human memories for offline replay and stabilization, Claude can tag salient events or write observations directly into a persistent memory store (such as a folder of memory notes).

将记忆视作对未来需求的预测

Memory as a Prediction of Future Needs

记录下一条规则或经过验证的事实，本质上是对未来会话实际需求的一种隐式前瞻预测。例如，在权威的持续学习基准测试 (Continual Learning Bench, CL-Bench) 1.0 中，AI 智能体会借助记忆笔记复盘失败教训、检验假设，并沉淀出用于解答未来数据库问题的操作准则。像 Claude Opus 5 与 Opus 5.5 这样的前沿模型已成功打通这一“认知闭环”：通过系统化管理记忆目录，其表现彻底碾压了没有任何记忆沉淀的无状态基线模型。

Writing down a rule or verified fact is an implicit prediction that a future session will need it. For instance, on the Continual Learning Bench (CL-Bench) 1.0, agents use memory to record failures, test theories, and establish rules for answering future database questions. Frontier models like Claude Opus 5 and Opus 5.5 successfully "close the loop," utilizing memory directories to radically outperform stateless baselines.

3. 判断显著性与行为引导

3. Judging Salience and Steering

当面对像通关经典游戏《精灵宝可梦·红》 (Pokémon Red) 这类超长周期任务时，不同代际的模型在判断“什么信息值得被记住”上展现出了截然不同的认知水准：

  • Sonnet 3.7 记录毫无取舍（在 225 个文件夹中疯狂创建了 413 份记忆文件），频繁记录肉眼可见的瞬时屏幕状态，最终将大量计算资源耗费在冗余的文件维护上，反而耽误了核心游戏流程；
  • Fable 5 则展现出了极高的筛选判断力，仅将高价值的战略规划、核心全局规则以及边缘异常行为（例如捕捉宝可梦时的精准时机差异）记录到精简有序的目录中，最终赢得的道馆徽章数量也实现了显著提升。

When tested on long-horizon tasks like playing Pokémon Red, models exhibited stark differences in what they deemed "worth remembering": * Sonnet 3.7 wrote indiscriminately (413 memory files across 225 folders), frequently duplicating visible screen states and eventually getting bogged down in redundant file upkeep rather than playing the game. * Fable 5 exercised selective judgment, writing strategic plans, overarching rules, and edge-case behaviors (e.g., varying timing when capturing Pokémon) into a streamlined directory, earning significantly more badges.

虽然早期模型往往受益于详尽的外部显式提示词（例如在每次作答前必须硬性提示它们“请先检索记忆文件”），但新一代前沿模型在获得充分自主权时反而表现更为出众——它们能够自发审视全局，独立甄别出哪些信息才是真正不可或缺的核心关键。

While older models benefit from explicit instructions (such as prompting them to read memory files before answering), frontier models perform best when given the freedom to autonomously judge what information is truly salient.

4. “做梦”机制如何优化智能体记忆

4. How "Dreaming" Optimizes Agent Memory

纠正记忆中的错误

Correcting Memory Mistakes

在执行任务的实时会话中，即时记录的笔记难免会夹杂误判，甚至随着外部环境的动态变化而产生认知漂移。此时，离线状态下的“做梦”机制就发挥了至关重要的校准作用：它赋予 Claude 将记忆笔记与完整原始会话记录逐一交叉比对的能力，从而敏锐发现破绽并重写修正错误。

Because in-session memory writing can capture errors or drift as environments change, offline dreaming allows Claude to cross-reference notes against raw session transcripts to catch and rewrite mistakes.

在《精灵宝可梦》的测试中，未经纠错的空间地图笔记曾导致 AI 智能体屡屡陷入悬崖落差等死循环导航陷阱，甚至因此彻底卡死、放弃任务。而在引入做梦机制后，Claude 在离线反思中精准定位了自己绘制地图时的坐标谬误，果断修正路线，最终顺利重返月见山 (Mt. Moon) 并成功抵达下一座城镇。

In Pokémon, uncorrected spatial notes caused agents to repeatedly fall into navigational traps and abandon progress. With dreaming enabled, Claude caught its mapping error, successfully re-entered Mt. Moon, and reached the next city.

构建全新的记忆表征（维基网络）

Building New Memory Representations (Wikis)

做梦机制赋予了 AI 智能体编织全新知识形态的能力——它能够将碎片化的笔记聚合成一套互相超链接的网络化页面集合，即“维基 (Wikis)”。面对企业内部文档等海量且复杂的非结构化语料库时，这套维基知识网络就如同一张高度清晰的认知导航图。

Dreaming enables agents to build interconnected collections of pages known as wikis. These serve as maps to sift through vast information corpora (such as internal company documents).

当维基知识网络与检索工具协同运作时，AI 智能体在处理跨多个文档的复杂长程推理任务时展现出了惊人的可扩展性，同时在单次查询中能为系统节省数以千计的 Token 开销。不过这也对工程调优提出了更高的要求：开发者必须精心设计引导指令，以防止生成的维基页面过度膨胀、退化为臃肿重叠的无效索引。

When combined with search tools, wikis help agents scale their performance on complex multi-document reasoning tasks while saving thousands of tokens per query. However, instructions must be carefully tuned to prevent wikis from ballooning in size or becoming redundant maps.

将核心笔记提升至记忆层级顶端

Promoting Notes Up the Memory Hierarchy

做梦过程的另一项关键使命，是将最为核心的经验提炼并提升至记忆层级的顶端。在这里，智能体执行框架 (Harness Systems) 可以在每次全新会话启动时，将其作为“注入上下文 (Injected Context)”预先加载。研究表明，过于冗长的初始指令反而会严重削弱大模型对规则的遵循能力，因此顶层上下文必须保持极度精炼——通常采用索引目录的形式（类似于 Claude Code 中的 MEMORY.md 索引文件），仅保留关键概要并按需指向底层更详尽的专项记忆文档。

Dreaming floats crucial notes to the top of the hierarchy, where harness systems can preemptively load them as injected context at the start of every session. Because large instruction files reduce adherence, the top layer must remain concise—often structured as an indexed header (like Claude Code’s MEMORY.md) pointing to deeper files.

5. 结语：向后反思，向前迈进

5. Conclusion: Thinking Backward, Looking Forward

构建高效的智能体记忆体系，关键在于在“会话中的实时记录”与“会话间的后台做梦”之间找到黄金平衡点。频繁的实时记笔记难免会分散 AI 智能体处理当前即时任务的专注力；而做梦机制则提供了一个条理分明的离线窗口，让模型得以从容“向后反思”——校对修正谬误、剔除陈旧无用信息，并为应对未来的全新会话打理出一套清晰高效的记忆金字塔。随着前沿基础模型的不断演进，这一融合了生物智慧的智能体记忆范式必将持续释放出更加深远的影响力。

Designing agent memory requires balancing active in-session logging with offline background dreaming. While real-time note-taking pulls an agent's attention away from its immediate task, dreaming provides a structured opportunity to look backward, correct mistakes, prune outdated information, and maintain efficient hierarchies for future sessions. As models advance, agent memory frameworks will continue to evolve.
