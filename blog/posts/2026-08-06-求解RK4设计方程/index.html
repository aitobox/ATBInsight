求解 RK4 设计方程

文章背景与核心概要

经典四阶龙格-库塔法（RK4）是求解常微分方程的基本数值工具，但在 20 世纪初，求解其参数必须满足的 8 个代数约束方程极为繁琐。本文回顾了 RK4 约束方程的历史背景与数学表达，展示了现代计算机代数系统（如 Mathematica）如何轻松求解这些欠定方程组。文章进一步演示了如何推导标准教科书参数、经典的 3/8 规则，并探讨了在早期受限硬件上优化的 Gill 算法等衍生变体。

概要

本文探讨了经典四阶龙格-库塔法（RK4）的历史与数学基础。通过审视 RK4 参数必须满足的一套代数约束条件——在 20 世纪初被历史性地称为手算“极其繁琐”的计算——文章展示了现代计算机代数系统（如 Mathematica）如何毫不费力地求解这些方程，揭示教科书中的变种，推导著名的 3/8 规则，并触及如 Gill 算法等专为早期硬件优化的特殊方法。

This article explores the historical and mathematical foundations of the classical fourth-order Runge-Kutta (RK4) method. By examining the set of algebraic constraints that RK4 parameters must satisfy—historically noted as "very tedious" to solve by hand in the early 20th century—the post demonstrates how modern computer algebra systems like Mathematica can effortlessly solve these equations, uncover textbook variants, derive the famous 3/8 rule, and touch upon specialized hardware-optimized methods like Gill's algorithm.

引言

在研究用于求解微分方程的龙格-库塔法时，[1] 中的一句话引起了我的注意：

While researching the Runge-Kutta method for solving differential equations, a line from [1] caught my attention:

"这些计算在 Kutta 的论文中并未给出（不过在 Huen (1900) 中有推导），它们非常繁琐。"

"These calculations, which are not reproduced in Kutta’s paper (they are however in Huen (1900)), are very tedious."

这里提到的计算指的是四阶龙格-库塔方法的参数必须满足的一套八个约束条件。这不禁让我思考，如果 Mathematica 在 1900 年就已经存在，它能为 Huen 先生那些“极其繁琐”的计算提供多少帮助。

The calculations in question refer to a set of eight constraints that the parameters of a fourth-order Runge-Kutta method must satisfy. It made me wonder how much assistance Mathematica might have provided to Mr. Huen in his "very tedious" calculations had it been available in 1900.

虽然我在这篇入门文章中广泛探讨了龙格-库塔方法，但在这里我想专门聚焦于其设计中的单个步骤：求解基础的设计方程组。

While I explore Runge-Kutta methods broadly in this introductory post, here I want to focus specifically on a single step in their design: solving the foundational set of design equations.

RK4 约束方程组

四阶龙格-库塔方法的参数必须满足以下由八个方程组成的方程组：

The parameters of a fourth-order Runge-Kutta method must satisfy the following system of eight equations:

\[ \begin{align*} b_1 + b_2 + b_3 + b_4 &= 1 \\ b_2 c_2 + b_3 c_3 + b_4 c_4 &= \frac{1}{2} \\ b_2 c_2^2 + b_3 c_3^2 + b_4 c_4^2 &= \frac{1}{3} \\ b_3 a_{32} c_2 + b_4(a_{42} c_2 + a_{43} c_3) &= \frac{1}{6} \\ b_2 c_2^3 + b_3 c_3^3 + b_4 c_4^3 &= \frac{1}{4} \\ b_3 c_3 a_{32} c_2 + b_4 c_4(a_{42} c_2 + a_{43} c_3) &= \frac{1}{8} \\ b_3 a_{32} c_2^2 + b_4(a_{42} c_2^2 + a_{43} c_3^2) &= \frac{1}{12} \\ b_4 a_{43} a_{32} c_2 &= \frac{1}{24} \end{align*} \]

首要的关键观察是这里有 10 个变量，但只有 8 个方程。由于该系统是欠定的，其解并不唯一。我们通常所认为的“那个”四阶龙格-库塔法，实际上只是“一种”四阶龙格-库塔法。

The first critical observation is that there are 10 variables and only 8 equations. Because the system is underdetermined, the solution is not unique. What we typically think of as the fourth-order Runge-Kutta method is actually just a fourth-order Runge-Kutta method.

使用 Mathematica 求解

为了缩小解的范围，我们可以引入额外的假设。例如，我们可以假设 \(b_2 = b_3\) 且 \(c_2 = c_3\)。有了这两个额外的约束条件，方程组就变成了唯一确定的，Mathematica 可以即刻完成求解：

To narrow down the solution, we can introduce additional assumptions. For instance, we might argue that \(b_2 = b_3\) and \(c_2 = c_3\). With these two extra constraints, the system becomes uniquely determined, and Mathematica can solve it instantly:

eqs = {
    b1 + b2 + b3 + b4 == 1,
    b2*c2 + b3*c3 + b4*c4 == 1/2,
    b2*c2^2 + b3*c3^2 + b4*c4^2 == 1/3,
    b3*a32*c2 + b4*(a42*c2 + a43*c3) == 1/6,
    b2*c2^3 + b3*c3^3 + b4*c4^3 == 1/4,
    b3*c3*a32*c2 + b4*c4*(a42*c2 + a43*c3) == 1/8,
    b3*a32*c2^2 + b4*(a42*c2^2 + a43*c3^2) == 1/12,
    b4*a43*a32*c2 == 1/24,
    b2 == b3,
    c2 == c3
};

vars = {b1, b2, b3, b4, c2, c3, c4, a32, a42, a43};

solution = Solve[eqs, vars]

执行这段代码将返回几乎所有数值分析教科书中介绍的标准龙格-库塔法所使用的精确参数集。

Executing this code returns the exact parameter set used for the standard Runge-Kutta method presented in nearly every numerical analysis textbook.

或者，如果您保留 \(b_2 = b_3\) 的要求，但在 \(c\) 系数中将 \(c_2 = c_3\) 替换为 \(2c_2 = c_3\)，Mathematica 将给出 龙格-库塔 3/8 规则 的系数，这是在某些特定标准下具有独特优势的变种。

Alternatively, if you retain the requirement \(b_2 = b_3\) but substitute \(2c_2 = c_3\) for the \(c\)-coefficients, Mathematica yields the coefficients for the Runge-Kutta 3/8 rule, a variant that offers distinct advantages under certain criteria.

历史背景与变体

1951 年，A. Gill [2] 发现了一种专门针对当时受限极其严重的计算机硬件优化的四阶龙格-库塔规则。这是一种引人入胜的方法，其特征是包含无理数参数——这是对 20 世纪中叶计算硬件局限性的巧妙工程应对。

In 1951, A. Gill [2] discovered a fourth-order Runge-Kutta rule specifically optimized for running on extremely constrained computer hardware of the era. It is a fascinating method featuring irrational parameters—a clever engineering response to the hardware limitations of mid-century computing.
