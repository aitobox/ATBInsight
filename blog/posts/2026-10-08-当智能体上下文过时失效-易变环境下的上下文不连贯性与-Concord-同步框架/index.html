当智能体上下文过时失效：易变环境下的上下文不连贯性与 Concord 同步框架

When Agent Context Goes Stale: Incoherence in Volatile Agent Context

Authors: Yingying Liu, Junzhou Fang, Chenxiong Qian
Published: arXiv:2610.05281 [cs.AI] (Submitted on 4 Oct 2026, last revised 6 Oct 2026)
Accepted to: AgenticOS Workshop at SOSP 2026
Links: View PDF | HTML Version

文章背景与核心概要

在当今的大语言模型 (Large Language Model, LLM) 生态中，AI 智能体 (AI Agent) 普遍通过调用外部工具 (例如读取工作区代码与文件) 来感知环境并指导自身的推理决策。然而，真实的工作区环境是高度动态易变的——当底层数据被人类用户、其他外部工具或协同智能体修改后，模型的上下文窗口中依然滞留着陈旧过时的数据，由于主流智能体运行时缺乏失效通知机制，智能体极易复用这些失效信息并做出错误的推理判断。针对这一严峻的上下文不连贯性难题，研究人员在 SOSP 2026 的 AgenticOS Workshop 上提出了名为 Concord 的上下文连贯性同步框架，通过源头追踪与主动变更检测，在智能体复用数据前动态执行更新、批注或屏蔽策略。评测结果显示，Concord 在新构建的 ConcordBench 基准测试上使各大前沿模型均恢复出与真实工作区一致的状态，且相比非 Oracle 最强基线节省了 46.4% 的 Token 消耗。该研究为解决易变环境下的智能体状态滞后问题提供了优雅的系统级解决方案，是通往可靠智能体操作系统 (AgenticOS) 迈出的关键一步。

核心内容概要

Summary

现代 AI 智能体 (AI Agent) 通常依赖从外部工具获取的观测信息 (例如读取工作区中的文件) 来辅助自身展开逻辑推理。然而，当这些底层数据源被人类用户、外部工具或其他并发智能体修改时，模型上下文窗口中保留的却依然是陈旧过时的历史内容。由于主流智能体运行时 (Agent Runtime) 普遍缺乏针对过时数据的失效与变更通知机制，智能体在后续步骤中往往会反复调用这些失效信息，进而对工作区当前的最新状态做出严重脱离实际的错误判断。

Modern AI agents often rely on observations gathered from external tools (such as reading workspace files) to inform their reasoning. However, when these underlying data sources are modified by users, external tools, or other agents, the model's context window still retains the outdated (stale) content. Because standard agent runtimes lack notification systems for stale data, agents frequently reuse this obsolete information and generate incorrect conclusions about the current state of their workspace.

为了从根本上解决这一问题，论文作者提出了 Concord——一个专为保持工具观测结果与可变数据源实时同步而设计的上下文连贯性保障框架。

To solve this issue, the authors introduce Concord, a context coherence framework designed to keep tool observations synchronized with mutable data sources.

Concord 框架的核心技术亮点包括：

Key highlights of the Concord framework include:

  • 源头链路追踪与变更检测 (Source Linking & Change Detection) ： 将每一次工具观测精准绑定至其数据源头，并主动监测数据源是否发生变更。
  • 灵活可配置的处理策略 (Configurable Handling Policies) ： 在智能体重新调用或复用陈旧上下文之前，自动完成过时信息的增量更新、显式批注或直接抑制屏蔽。
  • 通用易扩展的架构设计 (General Applicability) ： 能够灵活适配各种主流智能体运行时与多样化的外部资源，具备极佳的通用性与可扩展性。
  • ConcordBench 基准评测表现 (ConcordBench Evaluation) ： 在针对文件内容动态修改而全新构建的基准测试集上，Concord 助力所有参与评估的前沿大模型均得出了与最新工作区状态完全一致的正确结论 (达到与完全知晓变更的 Oracle 基线相同的恢复水准) ，同时相较于最强的非 Oracle 基线方案，成功节省了 46.4% 的 Token 消耗。
  • Source Linking & Change Detection: Links every tool observation to its origin and actively monitors for modifications.
  • Configurable Handling Policies: Automatically updates, annotates, or suppresses stale context before the agent reuses it.
  • General Applicability: Works across various agent runtimes and external resources, making it easily extendable.
  • ConcordBench Evaluation: Tested on a newly constructed benchmark where observed file contents undergo edits. Concord achieved answers consistent with the restored workspace state across all evaluated frontier models (matching the oracle recovery count) while utilizing 46.4% fewer tokens than the strongest non-oracle baseline.
