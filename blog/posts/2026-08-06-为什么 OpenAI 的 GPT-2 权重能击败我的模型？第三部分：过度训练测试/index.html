为什么 OpenAI 的 GPT-2 权重能击败我的模型？第三部分：过度训练测试

文章背景与核心概要

虽然作者自研训练的 GPT-2 架构模型在测试集交叉熵损失上达到或超越了 OpenAI 原始 Small 模型的水平，但在指令微调（IFT）评估中依然落后。本文深入探讨了“过度训练”（超过 Chinchilla 最优阈值的 Token 训练）是否为解释 OpenAI 优异表现的隐性变量。作者利用扩展的计算预算进行了两组实验（64 亿 Token 单 Epoch 训练和 32 亿 Token 双 Epoch 训练）。实验表明，过度训练成功降低了测试 Loss 并接近 OpenAI Medium 模型的指标，但对指令遵循能力的提升微乎其微，其假说目前仍未获得明确证实。

执行摘要

Executive Summary

虽然作者自定义训练的类似 GPT-2 架构的模型在测试集交叉熵损失（cross-entropy loss）上达到了与 OpenAI 原始 Small 模型相当甚至更优的水平，但在指令微调（IFT）评估中却持续表现落后。

While the author's custom-trained GPT-2-style models achieved competitive or superior test set cross-entropy loss compared to OpenAI's original small model, they continued to underperform on instruction fine-tuning (IFT) evaluations.

本篇博文探究了过度训练（overtraining）——即在超过 Chinchilla 最优阈值数量的 Token 上训练模型——是否就是解释 OpenAI 优异性能的隐性变量。作者在扩展的预算下运行了两次实验（一个 64 亿 Token 的单 Epoch 运行和一个 32 亿 Token 的双 Epoch 运行）。

This post investigates whether overtraining—training a model on more tokens than the Chinchilla-optimal threshold—is the hidden variable explaining OpenAI's superior performance. The author ran two experiments overextended budgets (a 6.4B token single-epoch run and a 3.2B token two-epoch run).

核心要点： * 测试 Loss 改善： 两款过度训练的模型均成功改善了测试集 Loss，指标紧追 OpenAI 的 Medium 模型。 * IFT 性能收益： 指令遵循方面的提升非常微小，几乎与统计噪声无法区分。 * 结论： 该假设目前尚无定论。虽然过度训练改善了原始的下一个 Token 预测能力，但并未带来指令微调性能上的即时、明确飞跃。

Key Takeaways: * Test Loss Improvements: Both overtrained models successfully improved test set loss, closely approaching OpenAI's medium model metrics. * IFT Performance Gains: Instruction-following gains were marginal and largely indistinguishable from statistical noise. * Conclusion: The hypothesis remains inconclusive. While overtraining improves raw next-token prediction, it does not provide an immediate, unambiguous leap in instruction fine-tuning performance.

定义过度训练 vs. 过拟合

Defining Overtraining vs. Overfitting

区分过拟合（overfitting）与过度训练（overtraining）至关重要： * 过拟合发生于模型记忆了特定的训练数据模式，而非学习可泛化的规律时。这普遍是有害的。 * 过度训练指的是 LLM 在超过 Chinchilla 最优 比例（大约每个模型参数对应 20 个 Token）的情况下继续接受训练。

It is crucial to distinguish between overfitting and overtraining: * Overfitting occurs when a model memorizes specific training data patterns rather than learning generalizable rules. It is universally detrimental. * Overtraining refers to training an LLM beyond the Chinchilla-optimal ratio (roughly 20 tokens per model parameter).

尽管 Chinchilla 经验法则表明算力预算最好均匀用于扩展参数量和 Token 数量，但过度训练在实际上往往具有必要性（例如当硬件限制了模型大小时，比如在移动设备上部署模型）。

While Chinchilla heuristics dictate that compute budgets are best spent scaling parameters and tokens equally, overtraining is often practically necessary (e.g., when hardware constraints limit model size, such as deploying models on mobile devices).

由于 OpenAI 在 2019 年（比 Chinchilla 论文早三年）使用 WebText（~100 亿 Token）训练了 GPT-2，按现代标准来看，他们拥有 1.24 亿参数的 Small 模型几乎可以肯定是被过度训练过的。

Because OpenAI trained GPT-2 in 2019—three years before the Chinchilla paper—using WebText (~10B tokens), their 124M-parameter small model was almost certainly overtrained by modern standards.

实验设计

The Experiments

为了测试过度训练是否能弥补性能差距，作者使用了专用训练集群（poppy）训练了两款模型： 1. 扩展 Token 模型： 在 64 亿独立 Token 上训练（比之前的基线翻倍）。 2. 多 Epoch 模型： 在标准 32 亿 Token 数据集上训练 两个 Epoch。

To test if overtraining bridges the performance gap, the author utilized a dedicated training rig (poppy) to train two models: 1. Extended Token Model: Trained on 6.4B unique tokens (double the previous baseline). 2. Multi-Epoch Model: Trained for two epochs over the standard 3.2B token dataset.

实验前预测

  • 两款模型在测试 Loss 上都将击败现有模型（90% 概率），且扩展 Token 模型表现优于双 Epoch 模型（70%）。
  • 两款模型在 IFT 评估上的得分都将高于先前的基线（70%），但依然低于 OpenAI 的 Small 模型（90%）。

Pre-Experiment Predictions

  • Both models would beat existing models on test loss (90% probability), with the extended-token model outperforming the two-epoch model (70%).
  • Both models would score higher on the IFT evaluation than previous baselines (70%) but still underperform OpenAI's small model (90%).

实验结果与评估

Results & Evaluation

1. 扩展训练模型（单次长 Epoch）

  • 状态： 在解决最初的 CUDA 流捕获错误后顺利完成。
  • 测试 Loss： 达到了 3.324953 的 Loss，显著击败了基线 Chinchilla 最优模型 (3.418784) 和 OpenAI 的 Small 模型 (3.499677)，并接近 OpenAI 的 Medium 模型 (3.231442)。

1. The Extended-Train Model (One Long Epoch)

  • Status: Completed successfully after an initial CUDA stream capture error.
  • Test Loss: Achieved a loss of 3.324953, significantly beating the baseline Chinchilla-optimal model (3.418784), OpenAI's small model (3.499677), and nearing OpenAI's medium model (3.231442).

2. 双 Epoch 模型

  • 状态： 顺利完成，未发生硬件错误。
  • 测试 Loss： 达到了 3.326482 的 Loss，表现与扩展 Token 模型几乎完全相同（完全在噪声误差范围内）。

2. The Two-Epoch Model

  • Status: Completed smoothly without hardware errors.
  • Test Loss: Achieved a loss of 3.326482, performing nearly identically to the extended-token model (falling well within the margin of noise).

结论

Conclusion

核心假设——即仅靠过度训练就能解释为何 OpenAI 的权重在指令微调评估中占据统治地位——依然未被证实。

The core hypothesis—that overtraining alone explains why OpenAI's weights dominate instruction fine-tuning evaluations—remains unproven.

虽然过度训练可以可靠地降低测试 Loss 并提升下一个 Token 的预测水平，但在这些配置下，它对指令遵循能力的影响充其量也是微乎其微的。极端的过度训练（例如怀疑 OpenAI 使用了多达 42 个 Epoch）是否能跨越这一门槛仍然是一个悬而未决的问题。然而由于计算资源和时间限制，作者计划接下来探索其他潜在的变量。

While overtraining reliably lowers test loss and improves next-token prediction, its impact on instruction following is marginal at best in these configurations. Whether extreme overtraining (such as the suspected 42 epochs used by OpenAI) would cross the threshold remains an open question. However, due to compute and time constraints, the author plans to explore alternative variables next.
