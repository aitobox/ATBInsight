# llama.cpp v1.0.0 正式发布：为本地 AI 生态奠定坚实基石

> # llama.cpp v1.0.0: A Stronger Foundation for the Local AI Ecosystem

**Published:** November 13, 2026  
**Authors:** Daniel Bevenius, Georgi Gerganov, merve (ggml-org)

---

### 文章背景与核心概要
作为当今开源 AI 领域最著名的轻量级推理引擎，`llama.cpp` 历经 3.5 年的高速演进与全球开源社区的共同打磨，终于正式迎来了具有里程碑意义的 **v1.0.0** 正式版本。本次发布标志着该项目正式引入严格规范的**语义化版本控制 (Semantic Versioning, SemVer)**，从底层确立了 C 语言应用程序接口 (Application Programming Interface, API) 与二进制接口 (Application Binary Interface, ABI) 的长期稳定性契约，使企业与开发者能够安心地进行生产级集成与长期维护。凭借底层 `ggml` 统一张量计算库，`llama.cpp` 不仅实现了从移动端、PC 到数据中心跨平台的全硬件覆盖，更已原生支持多达 150 多种主流大语言模型 (Large Language Model, LLM) 架构变体与投机解码加速技术。作为端侧和私有化 AI 推理事实上的“黄金基石”，`llama.cpp v1.0.0` 的发布将为全球开发者构建自主可控、极速高效的本地 AI 应用生态提供坚不可摧的支撑。

---

## 📌 核心概要

> ## 📌 Summary

`llama.cpp v1.0.0` 的推出，标志着本地 AI 基础设施演进历程中一座至关重要的里程碑。在过去的 3.5 年中，该项目已迅速成长为全球不可或缺、极致轻量且功能全面的跨平台私有化 AI 推理中枢。随着本次正式版的发布，`llama.cpp` 与底层的张量计算库 `ggml` 正式引入了严格规范的**语义化版本控制 (SemVer)**，以此全面保障 API 与 ABI 的长期稳定性，为全球广大开发者以及依赖于该生态的各类下游软件集成，筑牢了一套值得长期信赖的坚实底座。

> `llama.cpp v1.0.0` marks a major milestone in the evolution of local AI infrastructure. Over the past 3.5 years, the project has grown into an essential, lightweight, and versatile platform for cross-platform and private AI inference. With this release, `llama.cpp` and `ggml` introduce formal **Semantic Versioning (SemVer)** to guarantee API/ABI stability, solidifying a dependable foundation for developers and downstream integrations worldwide.

## 语义化版本更新规范

> ## Semantic Version update rules

以下规范适用于所有采用[语义化版本控制 (Semantic Versioning, SemVer)](https://semver.org)的 [ggml-org](https://huggingface.co/ggml-org) 开源项目：

> The following rules apply to all [ggml-org](https://huggingface.co/ggml-org) projects using [semantic versioning](https://semver.org):

| 变更类型 (Change type) | 版本号递增规则 (Bump) |
| :--- | :--- |
| **主版本号 (MAJOR)** | 对 `./include` 中的公开 C 语言 API 引入不兼容的重大破坏性变更 |
| **次版本号 (MINOR)** | 向后兼容的新特性、计算后端更新、新模型架构支持或新增 API |
| **修订版本号 (PATCH)** | 不涉及任何 API 变动的缺陷修复 (Bug fix) |

## 项目研发与持续集成

> ## Development

本项目的蓬勃生机，源自令人惊叹的全球开源社区的鼎力支持。随着大模型能力的突飞猛进，我们也在研发全生命周期中严谨、深思熟虑地深度引入大模型辅助工程。在此过程中，恪守高品质的代码标准、牢牢掌控整体架构设计的演进方向，并透彻理解底层实现的每一处细节，始终是团队最为核心的首要原则。

> The project thrives thanks to an incredible open-source community. As AI capabilities rapidly advance, we continue to thoughtfully integrate LLMs into our development cycle. Maintaining a high-quality codebase, keeping control of the architecture, and understanding implementation details remain our top priorities.

为了支撑更为敏捷的研发迭代速度，我们正在大规模扩展持续集成 (Continuous Integration, CI) 基础设施。依托 Hugging Face 所提供的先进技术支撑——例如 [HF Buckets](https://huggingface.co/docs/huggingface_hub/en/guides/buckets) 与 [HF Jobs](https://huggingface.co/docs/huggingface_hub/en/guides/jobs)，我们能够严密检验合入 `master` 主分支的每一行代码改动，全方位确保软件的逻辑正确性。与此同时，在来自 NVIDIA、AMD、Qualcomm、Arm、IBM 以及 Intel 等芯片巨头所提供的多元硬件支持下，我们持续在所有主流计算硬件平台上增设自托管运行节点 (Self-hosted Runners)。

> To support faster development, we are heavily scaling our CI infrastructure. Thanks to Hugging Face technologies like [HF Buckets](https://huggingface.co/docs/huggingface_hub/en/guides/buckets) and [HF Jobs](https://huggingface.co/docs/huggingface_hub/en/guides/jobs), we ensure correctness for every change landing on the `master` branches. With hardware support from NVIDIA, AMD, Qualcomm, Arm, IBM, and Intel, we continue to add self-hosted runners across all major hardware platforms.

## 计算后端与模型架构支持

> ## Backend and model coverage

作为 `llama.cpp` 底层的核心机器学习推理引擎，`ggml` 的精妙架构使其能够通过编译为动态链接库的专用后端算子，在几乎所有类型的计算硬件上高效驰骋。若想查阅当前已实现的完整后端计算支持列表，请参阅[此处官方源码仓库](https://github.com/ggml-org/ggml/tree/master/src)。

> The underlying machine learning engine of `llama.cpp`—`ggml`—is designed to run on virtually any hardware through dedicated backends compiled as dynamic libraries. A complete list of implemented backends can be found [here](https://github.com/ggml-org/ggml/tree/master/src).

<video autoplay="" controls="" loop="" muted="" playsinline="" src="https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/llama.cpp/llama-cpp-hardware-coverage-final.mp4"></video>

我们始终坚定不移地为各类模型拓扑架构提供全面且持久的适配支持。截至目前，`llama.cpp` 已经原生支持超过 [150 种模型架构变体](https://github.com/ggml-org/llama.cpp/tree/master/src/models)，并完整兼容当前学术界与工业界所有主流的投机解码 (Speculative Decoding) 加速算法。

> We are committed to providing continuous support for all model architectures. Currently, `llama.cpp` supports over [150 architecture variants](https://github.com/ggml-org/llama.cpp/tree/master/src/models) and all mainstream speculative decoding methods.
