# HBQ：兼顾硬件效率与精度的分层块量化架构，加速大模型推理

> # HBQ: Hierarchical Scaling Block Quantization with Hardware-Efficiency-Aware Design for Accurate LLM Inference

### 文章背景与核心概要

随着大语言模型 (Large Language Model, LLM) 规模的不断激增，海量参数给端侧与数据中心推理带来了巨大的内存带宽与能耗负担，量化压缩技术因而成为突破这一算力瓶颈的关键钥匙。然而，传统块量化 (Block Quantization, BQ) 架构在硬件执行效率与模型输出精度之间存在着显著的矛盾：采用大分块能通过充分摊薄反量化和累加成本来大幅提升芯片吞吐，却因数值动态范围受限而导致精度严重劣化；小分块虽能保留精度，却带来了沉重的硬件开销。针对这一两难困局，入选微体系结构顶级学术会议 MICRO 2026 的学术研究提出了 **HBQ (Hierarchical Block Quantization)** 架构。该方法将大尺寸分块与超低开销的有效数 (Significand, SIG) 缩放相结合，在第二层分级中精准补偿了大分块带来的量化误差，同时完美适配了权重与激活值迥异的统计分布特性。在 28nm ASIC 专用加速芯片上的实测表明，HBQ 实现了对权重、激活值与 KV Cache 的端到端量化支持；在保持甚至超越更高位宽精度的前提下，相较于当前最先进的仅权重量化技术实现了 **2.3 倍的面积效率与 4.6 倍的能效提升**，相比经典块量化方案系统能耗降低最高达 3.3 倍，为大语言模型的高效硬件落地提供了突破性的新路径。

## 📌 内容总结

> ## 📌 Summary

**HBQ (Hierarchical Block Quantization)** 是一套兼顾硬件执行效率感知、专为大语言模型 (Large Language Model, LLM) 高精度推理打造的创新量化框架。通过深入探索 Block Quantization (BQ) 中硬件效率与计算精度之间的权衡关系，研究人员发现：采用较大的数据分块虽然能够通过摊薄反量化与数据累加的硬件开销来提升芯片效率，但往往会造成严重的模型精度下降。为破解这一两难困境，HBQ 提出了创新的分层量化策略——以大分块作为第一层基础，并引入硬件开销极低的有效数 (Significand, SIG) 缩放作为第二层量化。这种分层设计既能契合权重与激活值截然不同的数值分布特性，又能高精度地弥补大分块带来的量化误差。在 28nm ASIC 专用加速器上的实测表明，HBQ 在模型精度与硬件效率两个核心维度上，均大幅超越了当前业内最先进的 Block Quantization 方案以及仅权重量化方法。

> **HBQ (Hierarchical Block Quantization)** is a hardware-efficiency-aware quantization framework designed for accurate Large Language Model (LLM) inference. By exploring the trade-offs in Block Quantization (BQ), the authors identify that larger blocks improve hardware efficiency (by amortizing dequantization and accumulation costs) but hurt accuracy. HBQ resolves this dilemma by pairing large blocks with low-overhead significand (SIG) scaling for second-level quantization, effectively compensating for errors while accommodating distinct weight and activation distributions. Implemented on a 28nm ASIC accelerator, HBQ significantly outperforms state-of-the-art BQ and weight-only quantization methods in both accuracy and hardware efficiency.

## 🔍 论文摘要

> ## 🔍 Abstract

Block Quantization (BQ) 技术通过同时对神经网络的权重与激活值进行低比特压缩，能够显著降低大模型的计算与存储开销，是加速大模型推理的强力手段。然而，该技术底层的架构设计空间至今仍未被充分挖掘。通过在硬件能耗与模型精度之间进行深入的系统性探索，我们发现分块尺寸 (Block Size) 是决定整体性能最为核心的权衡要素：分块越大，反量化计算与数据累加所耗费的硬件成本被摊薄得越彻底，芯片运行效率也就越高；然而，过大的分块会导致量化误差急剧积累，从而显著损害模型输出的准确率。

> Block Quantization (BQ) enables efficient LLM inference by quantizing both weights and activations, but its design space remains underexplored. Through hardware-accuracy design space exploration, we identify block size as a key trade-off: larger blocks improve hardware efficiency by amortizing dequantization and accumulation costs, but degrade accuracy. 

正是基于这一深刻洞察，我们提出了分层块量化架构 **HBQ (Hierarchical Block Quantization)**。该架构创造性地将粗粒度的大尺寸分块与开销极低的有效数 (Significand, SIG) 缩放机制深度融合，构建起精巧的第二级量化体系。通过 SIG 缩放微调，不仅能够精确补偿大分块粗放量化所带来的精度损失，还能自适应地契合权重与激活值各自独特的统计分布模式，实现精度与算力成本的双赢。

> Motivated by this insight, we propose **Hierarchical Block Quantization (HBQ)**, which combines large blocks with low-overhead significand (SIG) scaling for second-level quantization. SIG scaling effectively compensates for large-block quantization errors while accounting for distinct weight and activation distributions. 

* **HBQ-A** 仅采用超紧凑的 W4A5 配置，便成功达到了 W4A16 级别的模型精度，且硬件占用面积比 NVFP4 更加精简。
* **HBQ-E** 在精度上全面超越现有 Block Quantization 方法的同时，将硬件成本进一步大幅削减了 17%。

> * **HBQ-A** achieves W4A16-level accuracy with W4A5 and lower area than NVFP4.
> * **HBQ-E** further reduces hardware cost by 17% while outperforming existing BQ methods in accuracy.

我们在 28nm ASIC 专用加速器上，全面实现了针对权重、激活值以及 KV Cache 的端到端 HBQ 硬件支持，并创新性地引入了部分和 (Partial-Sum) BQ 技术以大幅削减累加过程中的能耗开销。实测数据表明：在保持相当精度的前提下，HBQ 相比当前顶尖的仅权重量化方案，实现了 **2.3 倍的面积效率与 4.6 倍的能效提升**；相比先前的各路 Block Quantization 方案，更是实现了 **1.6 至 3.3 倍的系统能耗削减与 1.5 至 3 倍的推理提速**。

> We implement HBQ for weights, activations, and KV cache in a 28nm ASIC accelerator and introduce partial-sum BQ to reduce EMA energy. At comparable accuracy, HBQ achieves **2.3×/4.6× higher area/energy efficiency** than state-of-the-art weight-only quantization and **1.6–3.3× lower system energy with 1.5–3× speedup** over prior BQ methods.
