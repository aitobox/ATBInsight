# ArtfulType: Markdown Writing App for the 68K Macintosh

### Summary
Sean Malseed (of "Action Retro") has developed **ArtfulType**, a Markdown editor designed for the original 68K Macintosh. Built using C and the Retro68 GCC-derived compiler, the project represents a modern attempt to bring contemporary writing workflows to vintage hardware.

---

### Project Details
*   **Source Code:** [GitHub Repository](https://github.com/ActionRetro/ArtfulType)
*   **Introduction:** [YouTube Video](https://youtu.be/HEheu_r9UGw?is=LZ_HTonXROFGnYcS)
*   **Technical Stack:** Written in C via the [Retro68](https://github.com/autc04/Retro68) compiler.

### Critical Perspective
While the technical achievement of running a Markdown editor on original Macintosh hardware is impressive, the application’s design philosophy clashes with the classic Mac aesthetic. 

ArtfulType utilizes a "distraction-free" full-screen mode—a concept that feels foreign to the 1984 Macintosh experience, where windowed multitasking was the defining paradigm. To be a truly "Mac-assed" app of that era, it would need to embrace the windowed interface that defined the platform.

### The BBEdit Alternative
For those seeking a more authentic experience, **BBEdit** remains the gold standard for Markdown on the Mac. As the application for which Markdown was originally created, it holds a unique place in history. However, there are practical limitations:
*   **Compatibility:** BBEdit 2.1.3 (the earliest public version) requires a more modern environment than the original 128K Mac can provide.
*   **System Requirements:** While it runs on System 5 (via [Infinite Mac](https://infinitemac.org/1987/System%205.0)), it fails to launch on System 3. 

Ultimately, while the allure of the 1980s retro Mac is strong, the utility of such machines is significantly hampered if they cannot support at least System 6.
