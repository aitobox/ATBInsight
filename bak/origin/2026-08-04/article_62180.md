# Nativ: Run AI models locally on your Mac

## Summary
Created by Prince Canuma (developer of the `MLX-VLM` library), **Nativ** is a new macOS desktop application that wraps Apple's MLX framework into a user-friendly interface. Similar to LM Studio, it offers a native chat experience alongside a localhost API server for running vision-LLMs and other AI models locally on Apple Silicon.

---

## Highlights

* **Developer:** Built by Prince Canuma, known for the `MLX-VLM` Python library.
* **Feature Set:** Combines an intuitive desktop chat interface with a localhost API server.
* **Smart Integration:** Automatically detects and utilizes existing MLX models stored in your local Hugging Face cache directory.
