# Notes from July 2026

> **Summary:** A busy month featuring talks on local language models, video game streaming for charity, open-source updates to Helmet and SQLite, migrating projects to Codeberg, and a curated list of fascinating reads on AI, browser quirks, and text rendering.

---

## Things I Did This July

* **Gave a Talk:** Spoke for ClimateAction.tech’s “Responsible AI Series” on [“What I know about local language models”](https://climateaction.tech/blog/responsible-ai-series-what-i-know-about-local-language-models/). While "Responsible AI" can sometimes feel like an oxymoron, I hope I shared some genuinely useful insights.
* **Charity Stream:** Participated in the [Zelda Dungeon Marathon](https://www.zeldadungeon.net/marathon/), marking my first time playing a video game (*The Legend of Zelda: Oracle of Seasons*) live on stream!
* **Released Helmet Updates:** Published a new version of [Helmet](https://helmet.js.org/), my Node security headers package. Most notably, this release speeds up `Content-Security-Policy` code by about 7% for common cases.
* **SQLite Advocacy:** Wrote about [strict tables](https://evanhahn.com/prefer-strict-tables-in-sqlite/), promoting an underrated and powerful SQLite feature.
* **Zelda Data Analysis:** Authored [a data-driven piece about the upcoming *Legend of Zelda: Ocarina of Time* remake](https://www.zeldadungeon.net/wisdom-of-the-crowd-using-data-to-make-predictions-about-the-ocarina-of-time-remake/). Can the wisdom of 32 *Zelda* experts accurately predict the new game? Time will tell.
* **Repository Migration:** Finished moving the majority of my repositories from GitHub to [Codeberg](https://codeberg.org/EvanHahn/). A few stragglers and mirrors remain, but those are larger projects requiring a bit more coordination.
