## Summary
Simon Willison explores the "pet" feature in Codex Desktop (reminiscent of the classic Office Assistant, Clippy) and discovers how to create custom animated desktop companions. Using **GPT-5.6 Sol** and **gpt-image-2**, he successfully generated "Pedalican"—a cute pelican on a bicycle that provides updates on Codex tasks. The article details the multi-step generative process, including character reference sheets, sprite generation on chroma-key backgrounds, and the open-source skills behind the implementation.

## Discovering Codex Desktop Pets

While exploring the Codex Desktop features originally announced back in May, I accidentally activated a "pet"—a little animated robot reminiscent of [Clippy](https://en.wikipedia.org/wiki/Office_Assistant)—and quickly learned that users can create their own custom pets. 

Naturally, I made one. Now, I have a cute little pelican on a bicycle bouncing around my desktop, giving me live updates on my Codex tasks.

> [!NOTE]
> You can watch the desktop companion in action in the [Pedalican video preview](https://static.simonwillison.net/static/2026/pedalican.mp4).

## How Pedalican Was Built

The most fascinating part of this process was watching how the custom pet came to life. After telling the AI I wanted a custom pet consisting of a pelican riding a bicycle, **GPT-5.6 Sol xhigh** handled the rest. 

Through several iterative rounds using [`gpt-image-2`](https://developers.openai.com/api/docs/models/gpt-image-2), the model generated the necessary sprite assets.

## Prompt Engineering for Game-Ready Sprites

That animation frame was created by executing [this prompt](https://github.com/simonw/pedalican-pet/blob/main/run/prompts/rows/waving.md) against the initial [character reference image](https://github.com/simonw/pedalican-pet/blob/main/run/api-generation/base.png), which was generated using [this base prompt structure](https://github.com/simonw/pedalican-pet/blob/main/run/prompts/base-pet.md):

> ```text
> Create one clean full-body reference sprite for Codex pet Pedalican.
> 
> Pet identity: A compact adorable baby pelican with a round cream-white body, soft coral-orange bill and feet, riding a tiny sky-blue bicycle [...]
> 
> Place a single centered pose on a perfectly flat pure magenta #FF00FF chroma-key background. Keep the full pet visible, compact, readable at 192x208, and easy to animate. [...]
> ```

I've been actively looking out for ways to leverage image generation to create simple, game-ready sprites, so digging into this mechanism was a rewarding experiment.
