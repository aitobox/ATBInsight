# condense-json 1.0

> **Summary:** `condense-json 1.0` is a lightweight Python library that optimizes JSON storage by identifying and replacing duplicated strings or substrings with a compact reference syntax. Designed to save space in SQLite logs for tools like [LLM](https://llm.datasette.io/), the library now officially reaches its 1.0 release after a year and a half of refinement.

---

## Overview

I'm trying to get braver at releasing 1.0 versions. This little library is a year and a half old now—I've applied some sensible and non-disruptive fixes and shipped the big 1.0 for it.

The primary goal of `condense-json` is to make it easier to store JSON that includes duplicated data from other related structures. I personally use it to save space in the SQLite logs generated by [LLM](https://llm.datasette.io/) (see [PR #1586](https://github.com/simonw/llm/pull/1586) for the latest iteration of that).

---

## How It Works

The library scans for strings or substrings present in a provided replacements object and replaces them with a special `{ "$r": ... }` syntax in the output. You can also easily reverse the effect using `uncondense_json()`.

### Example

**Input JSON:**
```json
{
  "foo": {
    "bar": {
      "string": "This is a string with foxes in it",
      "nested": {
        "more": ["Here is a string", "another with foxes in it too"]
      }
    }
  }
}
```

**Replacements Object:**
```json
{"1": "with foxes in it"}
```

**Result of `condense_json(input_json, replacements)`:**
```json
{
  "foo": {
    "bar": {
      "string": {"$r": ["This is a string ", {"$": "1"}]},
      "nested": {
        "more": ["Here is a string", {"$r": ["another ", {"$": "1"}, " too"]}]
      }
    }
  }
}
```
